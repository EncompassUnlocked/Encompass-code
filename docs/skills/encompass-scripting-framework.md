# Encompass Scripting Framework

Covers the **ICE Secure Scripting Framework**: JavaScript for Custom Forms, Custom Tools, and Plugins — scripting objects (Application, Auth, Http, Loan, Session), form controls, event handling, and debugging patterns.

**Example prompts:**

- *"Write a button click script that hard-stops if field 1109 is empty."*
- *"Log every change to CX.AUDIT.LOG with a timestamp and user ID."*
