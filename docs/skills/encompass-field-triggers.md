# Field Triggers (Advanced Coding)

Writes, explains, and troubleshoots **Advanced Coding rules** in Encompass — Field Triggers, Field Data Entry validation, Milestone Completion conditions, Loan Form Printing rules, and Advanced Conditions, all in VB.NET.

**Example prompts:**

- *"When field 4002 changes, check if the value is greater than 100 and alert the user."*
- *"When CX.LOAN.TYPE is set to 'HELOC', set field 1172 to today's date."*
