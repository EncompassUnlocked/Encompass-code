# EMPKG Package Editor

Creates, edits, and repairs Encompass **.empkg package files** — adding custom fields to manifest.xml, remapping field IDs in form controls, fixing field naming issues, and repackaging .emfrm form HTML.

**Example prompts:**

- *"Add CX.UW.MATRIX.1 through .10 to this empkg's manifest."*
- *"This form's field IDs have too many dots — fix and repackage it."*
