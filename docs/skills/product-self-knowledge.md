# Product Self-Knowledge

Gives Claude accurate, current knowledge of the **Claude ecosystem** — model versions, context windows, pricing, Claude Code features, and the API — so it stops answering from stale training data.

**Example prompts:**

- *"Which Claude model should I use for writing Encompass code on a budget?"*
- *"What's the context window and pricing for the current models?"*
