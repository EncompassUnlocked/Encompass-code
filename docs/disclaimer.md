# Disclaimer

## Use at your own risk

All code, guides, and skills on this site are provided **as-is, without warranty of any kind**. Every Encompass environment is configured differently — field IDs, business rules, personas, and workflows vary from lender to lender. Code that works perfectly in one environment may behave differently in yours.

**Before using anything from this site in production:**

1. **Always test in a sandbox or test environment first.** Never paste code directly into a production instance.
2. **Review every field ID.** Custom fields (anything starting with `CX.`) are examples from a demo environment — replace them with your own.
3. **Understand what the code does before you run it.** Every guide includes a plain-English explanation for exactly this reason. If something is unclear, don't run it.
4. **Follow your company's change management process.** Your compliance and IT teams exist for good reasons.
