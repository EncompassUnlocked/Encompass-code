# Contributing to Encompass Unlocked

This is a community library — contributions from fellow Encompass admins are very welcome.

## What to contribute

- **Working code** — business rules, field triggers, custom field calculations, web form scripts, SSF tools
- **Fixes** — corrections to existing guides, better explanations, edge cases we missed
- **Guides** — a write-up of something you built that other admins would want

## Ground rules

1. **Sanitize everything.** No company names, borrower data, production field values, or proprietary configurations. Custom field IDs should be generic examples (`CX.EXAMPLE.FIELD`).
2. **Test before you submit.** Code should work in a current Encompass environment. Note the version/context it was tested in (Desktop vs. Web, SSF vs. Advanced Coding).
3. **Follow the page format** used across the site: what it does → the code → how to use it → notes. Plain English explanations, no fluff.
4. **You own your contribution** and agree to license it under this repo's [MIT License](LICENSE).

## How to submit

- Open a **pull request** with your guide as a new `.md` file in the right `docs/` folder (and add it to `mkdocs.yml` nav), or
- Open an **issue** describing what you'd like to share if you're not comfortable with Git — we'll help you get it in.

Thanks for helping other admins unlock more of Encompass!
